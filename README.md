## ✨ Features & Overview

- **Real-time Live Timetable**: Auto-resolving schedule tracker showing current, upcoming, and completed lectures.
- **Class Change Alerts**: Real-time crowd-verified class delays, cancellations, and room changes.
- **Academic Notices & Exam Schedules**: Instant updates on department notices, assignments, and exam timetables.
- **Offline Mode**: Local caching ensuring instant schedule access even without internet connection.
- **Push & Pre-Class Reminders**: Automated 5-minute pre-class alerts and FCM push notifications.
- **In-App Auto Updater**: Automatic updates and version verification directly within the app.
